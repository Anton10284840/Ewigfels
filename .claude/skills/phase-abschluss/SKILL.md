# Phase/Feature abschließen

1. `PROGRESS.md`: Status-Spalten anpassen (⬜ 🟨 ✅ ❌), Datum oben setzen. Nur ehrlich „getestet“, wenn der Nutzer es gebaut/gespielt hat.
2. Prüfen, ob alles Externe in `CREDITS.md` steht.
3. Zusammenfassung an den Nutzer, auf Deutsch, drei Teile:
   - **Fertig:** was jetzt geht.
   - **Du im Editor:** exakte Klickfolge (Menü → Untermenü → Knopf).
   - **Als Nächstes:** ein Satz.
4. Commit mit aussagekräftiger deutscher Nachricht, ein Feature pro Commit.
