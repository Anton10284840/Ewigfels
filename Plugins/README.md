# Plugins

- `ThirdParty/` – Drittanbieter-Plugins. **Nicht im Repo.** Installieren mit `Scripts/Tools/Install-Plugins.ps1` (Liste: `Scripts/Tools/Plugins.json`, Bewertung: `docs/PLUGINS.md`).
- Eigene Plugins (z. B. Editor-Tools ab Phase 2) kommen direkt nach `Plugins/<Name>/` und werden versioniert.
