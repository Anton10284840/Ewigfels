# ComfyUI-Workflows

Hier liegen alle Workflows als exportierte `.json` (ComfyUI: *Workflow → Export*) und die Prompt-Listen.
Bilder selbst gehören nach `art/concepts/<region|charakter>/` (nicht in Git, OneDrive-Backup).

Erlaubte Modelle: nur die in `docs/KI_LIZENZEN.md` mit ✅. Jedes neue Modell zuerst in `CREDITS.md` eintragen.

Namensschema: `WF_<Zweck>_<Modell>.json`, z. B. `WF_Moodboard_FluxSchnell.json`, `WF_TileTexture_SDXL.json`.
